# Neo Finance — автономный Android APK без Capacitor

## Что это

Это тонкая нативная Android-оболочка на Android WebView. Она упаковывает HTML/CSS/JS текущего Neo Finance внутрь APK, использует `WebViewAssetLoader` с HTTPS-подобным локальным origin и не требует Capacitor. В APK не включено разрешение `INTERNET`: интерфейс и база IndexedDB работают локально с первого запуска. Service Worker отключён только для Android-сборки, потому что все файлы уже лежат внутри APK.

Официальное основание: Android Developers рекомендует `WebViewAssetLoader` для загрузки локальных ресурсов через `https://` URL вместо `file://`, чтобы сохранить совместимость с same-origin API. См. https://developer.android.com/develop/ui/views/layout/webapps/load-local-content

## Что нужно установить на Windows

1. Node.js LTS (у тебя уже используется в проекте).
2. Android Studio.
3. В Android Studio → SDK Manager установи **Android SDK Platform 36** и **Android SDK Build-Tools 35.x или 36.x**.
4. Android Studio включает Java Runtime. Скрипт пытается найти его автоматически. Требуется JDK 17 или новее.
5. При первом запуске нужен интернет, чтобы скачать Gradle и Android-зависимости. Само готовое приложение после установки работает офлайн.

## Как собрать

1. Сначала сохрани отдельный JSON-бэкап в работающем Neo Finance.
2. Распакуй архив этого комплекта **прямо в корень текущего проекта**, например `C:\Projects`. Новые файлы `vite.android.config.ts` и `android-wrapper` должны лежать рядом с `package.json` и `src`.
3. Открой PowerShell в `C:\Projects`.
4. Выполни:

```powershell
powershell -ExecutionPolicy Bypass -File .\android-wrapper\build-apk.ps1
```

5. Когда скрипт завершится, APK будет здесь:

`C:\Projects\android-wrapper\app\build\outputs\apk\debug\app-debug.apk`

Это debug APK, подписанный стандартным debug-ключом Android SDK; он подходит для установки и проверки на личном телефоне. Не загружай debug APK в Google Play.

## Важно перед первым запуском

APK и браузерная PWA используют **разные origin и отдельные хранилища**. IndexedDB/LocalStorage из браузера автоматически не перейдут в APK. Чтобы перенести данные:

1. Экспортируй обычный JSON-бэкап в текущем Neo Finance.
2. Установи APK.
3. Внутри APK открой Настройки → резервное копирование → импорт JSON.
4. После импорта проверь счета, транзакции, переводы и категории; сохрани новый JSON-бэкап.

В оболочке реализованы системный выбор файла для импорта и системный диалог сохранения JSON/CSV-экспорта. Финансовые записи хранятся внутри WebView IndexedDB. Данные сохраняются между обычными запусками и обновлениями APK с тем же `applicationId`, но удаление приложения/очистка данных Android может стереть их; держи внешний JSON-бэкап.

## Границы текущего пакета

- В архиве находятся исходники оболочки и автоматический скрипт сборки, **а не готовый `.apk`**: для компиляции требуется Android SDK, которого в среде подготовки архива нет.
- Сборка создаёт debug APK. Для публикации в Google Play нужно отдельно настроить release-подпись и проверить требования Google Play на момент публикации.
- В Android-сборке Google Fonts не загружается; используется системный шрифт, чтобы приложение не делало сетевые запросы и было полностью автономным.
- Перед тем как хранить единственные копии финансовых данных на телефоне, проверь на реальном устройстве импорт/экспорт JSON и CSV, перевод между счетами, перезапуск, режим полёта и обновление APK поверх предыдущей версии.
